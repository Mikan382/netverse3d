# ui

Package dùng chung: Thành phần giao diện dùng chung.

- Stack: CSS, JavaScript
- Milestone: M1
- Trạng thái: token giao diện Saigon Soft-Future và mục Nền tảng của thư viện.

Từ thư mục gốc, chạy `pnpm ui:library` để mở thư viện và `pnpm --filter @netverse/ui test` để kiểm token. Ứng dụng nhập `@netverse/ui/tokens.css` một lần ở layout.

Phông Be Vietnam Pro được phân phối qua Fontsource theo SIL Open Font License 1.1. Bản xuất thư viện kèm tệp giấy phép của phông.

Trước khi đưa mã vào đây, đọc [chuẩn thành phần](../../docs/wiki/engineering/component-standard.md).
